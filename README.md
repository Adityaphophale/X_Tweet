## Installation 🛠️

Since the project primarily consists of a Jupyter Notebook, there are no explicit installation steps outlined in the provided files. To use the project, you will need:

1.  **Jupyter Notebook:** Ensure you have Jupyter Notebook installed. You can install it using pip:

    ```bash
    pip install notebook
    ```

2.  **Dependencies:** Open `X_AGENT.ipynb` in Google Colab and run the following commands to install required packages:

    ```bash
    !pip install notebook
    !pip install pandas
    !pip install numpy
    !pip install google-generativeai
    ```

    To ensure you are using the latest version of the Gemini library in Colab:

    ```bash
    !pip uninstall -y google-generativeai
    !pip install -U google-generativeai
    ```


## Quick Start 🚀

1. Open [Google Colab](https://colab.research.google.com/).
2. Upload `X_AGENT.ipynb`.
3. Run all cells sequentially.
4. Enter your API key securely when prompted.
5. Start generating tweets!
